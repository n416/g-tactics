## 試したこと（重要）

### ✅ 宇宙（星空）— 成功。そのまま使える

`tmp-terrain-test/gen.mjs` → `space.svg`。

- シード固定の線形合同法で星を配置し、**端から半径 r 以内の星を x±256 / y±256 にも複製**
  することで、継ぎ目を「美的判断」ではなく**構造的な不変条件**として保証している。
- 検証済み: 円81個、端をまたぐ2箇所すべてに対の円が存在、欠落ゼロ。
- 6346 bytes。外部参照なし。

**成功した理由**: 「点を散らす」という手段と「星空」という題材が一致していた。

### ❌ 地上（草原）— 2回失敗

`tmp-terrain-test/gen-ground.mjs` → `ground.svg`（現在は2回目の状態）。

| 回 | 指示 | 結果 |
| --- | --- | --- |
| 1 | 「2次ベジェで葉を1本ずつ描く」 | **笹の葉／迷彩**。制御点を `w*1.5` 外側に膨らませたため、根元(w=3〜7)より中間が太い＝葉の形。縦横比も 5:1 で太すぎ、170本で密集しすぎ |
| 2 | 幾何を厳密指定（単調に細くなる / 縦横比 1:15〜25 / 本数70-90 / 風向き統一 / 不透明度down） | **流星群**。細い＋疎ら＋傾きが揃う＋暗い＝雨 |

**失敗の本質（3回目に活かすこと）**:
草が草に見えるのは「**地面から生えている**」から。両方とも濃紺の上に線／葉が浮いているだけで、
脳が草と解釈しない。足りないのは太さでも本数でもなく、以下:

- **地面の層がない**（草は何かから生えている）
- **株（tuft）になっていない**（本物の草は数本ずつ束で生え、均等に散らばらない）
- **根元が揃っていない**

パラメータの問題ではなく approach の問題、というのが中断時点の見立て。

### 判明した副次的な問題

**壁紙効果**: 継ぎ目が無くても、タイルを小さく表示すると**繰り返しが目に見える**
（128px 表示で同じ塊が規則的に並ぶのが分かった）。継ぎ目とは別問題。
タイルを使う限りついて回る。

## 方針の選択肢（ユーザー未決）

中断時点で以下を提示し、回答前にセッションが終わった。**まずここを決めること。**

1. **地形が分かればいい（提示時の推奨）** — 写実を諦め、色＋粗い示唆に切り替える。
   CSS グラデーション中心なら継ぎ目も壁紙効果も原理的に出ない。任意サイズに伸びる。
   このゲームのUIは濃紺のフラットなので、写実的な草の方がむしろ浮く。
   - 宇宙 ✅（星空はそのまま流用）
   - 仮想空間 → `repeating-linear-gradient` の格子（ほぼ自明）
   - 地上/水中/空中 → 色のグラデーション＋緩い地層/光の筋/雲の帯
2. **写実で頑張る** — 「株（tuft）＋地面の層」という構造で3回目を試す。外す可能性あり。
3. **タイルをやめて1枚絵** — 原作が砂漠の一枚絵だったのはこれが一番楽だから。
   継ぎ目も壁紙効果も消えるが、全画面を埋める引き伸ばしと、画像の用意（AI生成なら別ツール）＋
   R2 配置が要る。
4. **後回し** — 背景は優先度が低い。「画像ちっちゃ」やインライン style 1300箇所の掃除へ回る。

## agy への発注で学んだこと

`.claude/skills/agy-delegation` のプレイブックに沿って運用した。追加で分かったこと:

- **形の指定を言葉でやると外す。** 「細長い草」は曖昧すぎた。幾何（縦横比・制御点の位置・
  単調性）で書くと従う。ただし**美的な良し悪しは幾何で書けない**ので、そこが限界。
- **シームレス性は「アルゴリズムの不変条件」として発注すると通る。**
  「継ぎ目のないタイルを描いて」は失敗するが、「端から r 以内の要素を反対側にも複製せよ」は通る。
- **検証は agy にも自分にもさせる。** 1回目、agy の実装は正しかったのに
  **こちらの検証（正規表現）が間違っていて**「折り返し未実装」と誤判定しかけた。
  検証は不変条件を直接コードで確かめること。
- プレビューHTML（タイルを敷き詰め、境界に赤線を重ねるトグル付き）を必ず作らせること。
  **単体のタイルを見ても継ぎ目は分からない。**
