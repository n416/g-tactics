# R-1 ブリーフ: 名称統一 — モード名を「個別戦」に統一

あなたはこのプロジェクトの実装担当です。ユーザー決定（2026-07-20）:
「個別戦闘」「防衛戦」「襲撃」等に揺れているモード名を**「個別戦」に統一**し、
**「防衛戦」というモード名は廃止**する。

## 命名ポリシー（これに従うこと）

- **モード/機能名**として使われている「個別戦闘」「防衛戦」→ すべて「個別戦」
- **役割語は残す**: 「防衛者」「防衛成功/防衛失敗」「防衛耐久」など、個別戦の中での
  攻守の役割を表す語は自然なので変更しない
- フレーバーテキスト（戦闘ログ内の「基地防衛システムの迎撃射撃！」等）も変更しない
- 変数名・関数名・APIパス・DBカラム（defense_battles 等）は**変更しない**。対象は利用者に見える文言のみ

## 変更対象（grep で全数確認してから作業すること。以下は判明分）

### frontend
- `components/nav.ts:47` 「防衛履歴」→「個別戦履歴」
- `pages/Battle.tsx`
  - :354 「個別戦闘（作戦）一覧」→「個別戦（作戦）一覧」
  - :398 「防衛データ作成」→「個別戦の設置」
  - :404 「現在のステータスと搭乗機体で防衛データを作成し...」→ 個別戦の説明文に書き換え
  - :493 モーダルタイトル「個別戦闘の発動」→「個別戦の発動」
  - :514 placeholder「防衛線の名前を入力」→「個別戦（作戦）の名前を入力」※「防衛線」は誤字でもある
- `pages/Base.tsx`
  - :285-286 「防衛作戦 未設定」「防衛戦ページから作戦を設置してください」→
    「個別戦 未設置」「出撃ページから個別戦を設置してください」
  - :311 「防衛履歴を見る」→「個別戦履歴を見る」
  - :358 砲台説明「防衛戦の開幕に迎撃射撃を行う。」→「個別戦の防衛時、開幕に迎撃射撃を行う。」
  - 「昨夜 N 件の襲撃」系のサマリ文言 → 「個別戦: 挑戦を受けた」等、個別戦だと分かる表現に
    （DEFENSE ALERT 等の英字装飾は雰囲気なので残してよい）
- `pages/Log.tsx` 「防衛履歴はありません」「DEFENSE LOG」見出し等 → 個別戦履歴系の表現に
- `pages/Replay.tsx` にモード名としての「防衛戦」があれば同様に

### backend（利用者に見えるメッセージのみ）
- `src/routes/defense.ts` のエラーメッセージ「すでに個別戦闘を設置しています。」→「すでに個別戦を設置しています。」等、
  「個別戦闘」「防衛戦」をモード名として含む message を「個別戦」に
- `src/routes/base.ts` 等に同様の文言があれば統一

## 検証

- `grep -rn "個別戦闘\|防衛戦" frontend/src backend/src` の残存が上記ポリシーの許容範囲
  （役割語・フレーバー・識別子）のみであることを確認して報告
- backend `npm run typecheck` / `npm test -- --run`、frontend `npm run build`
- テストのアサーションが旧文言に依存して落ちた場合は、テスト側の期待値を新文言に追随させる
