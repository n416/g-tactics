# 基地・施設システムの経済バランス表と設計根拠

## 1. 現行経済の実態調査

* **機体価格帯**: 400〜850G 程度が主流 (`backend/migrations/0001_baseline.sql` 参照)。
* **初期資金**: 1000G (`backend/src/routes/auth.ts` の `initialMoney = 1000` より)。
* **戦闘報酬**: 勝利時基本報酬は 10〜数十G 程度 + 連勝ボーナス (10G × 連勝数)。敗北時でも 10G 前後取得可能 (`backend/src/utils/battleRewards.ts`)。
  * つまり、連勝を重ねることでまとまった資金が手に入る構造。

## 2. 施設効果と建設・強化コスト案

施設の強化による恩恵を段階的に設定。初期(Lv1)は手軽に建設でき、Lv5 はエンドコンテンツとして設定。

| 施設名 | 効果内容 | Lv1 | Lv2 | Lv3 | Lv4 | Lv5 | 建設/強化コスト (G) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **発電所** | 時間収入 (G/時) | +20 | +50 | +100 | +200 | +400 | 500 / 2k / 8k / 20k / 50k |
| **修理ドック** | 耐久回復速度倍率 | 1.2倍 | 1.5倍 | 2.0倍 | 2.5倍 | 3.0倍 | 1000 / 3k / 10k / 25k / 60k |
| **砲台** | 迎撃射撃 (回数/威力) | 1回 (小) | 1回 (中) | 2回 (中) | 2回 (大) | 3回 (大) | 800 / 2.5k / 8k / 20k / 50k |
| **博物館** | 機体展示枠数 | 4枠 | 8枠 | 12枠 | 18枠 | 24枠 | 2000 / 5k / 15k / 30k / 80k |
| **工場** | ショップ購入割引 | 2% | 5% | 8% | 12% | 15% | 8000 / 15k / 30k / 60k / 120k |

## 3. 時間収入の受け取り方式の提案

**提案: 訪問時精算 ＋ 蓄積上限（キャップ）方式**

*   **仕様**: 発電所には「最大蓄積時間」（例：12時間分）が設定されており、それを超えると溢れる。基地ページを訪問するか、特定のボタンを押した際に精算されて手持ち資金に加算される。
*   **放置ゲー化しない理由**: キャップが存在するため、長期間放置しても資金は一定以上増えない。定期的なログインとアクティブなプレイ（戦闘でキャップを消費する、あるいは溢れる前にログインする）を促す仕組み。また、戦闘報酬（特に連勝ボーナス）の効率を収入より高く保つことで、メインの資金源はあくまで戦闘とする。

## 4. 発電所収入と戦闘報酬の試算比較

*   **1日の戦闘報酬 (アクティブプレイ)**: 1日20戦、勝率50%、平均連勝3と仮定。
    *   10勝 × (基本20G + 連勝ボーナス平均30G) = 500G
    *   10敗 × 15G = 150G
    *   **計: 約650G/日** (連勝が伸びればさらに増加。またシミュレーター等ではなく通常戦闘)
*   **発電所 (Lv2) の1日収入**:
    *   50G × 24h = 1200G (※キャップ12時間なら1日2回ログインで全回収)
    *   初期〜中盤は機体の乗り換えや施設強化で資金が枯渇しやすいため、1日1000G前後の収入はプレイを支えるベーシックインカムとして機能する。
    *   Lv5(400G/h = 9600G/日) まで育てば大きな収入源になるが、そこに到達するための投資額(約8万G)を回収するのに日数がかかるため、経済バランスは崩壊しない。

## 5. 論点リスト

*   **地形属性の付与条件**: 基地の「地形属性」はアカウント作成時にランダムに決まるのか、任意に変更可能なのか？ (防衛戦の戦場に影響すると思われる)
*   **基地の所有形態**: 基地は1ユーザーにつき1つか、複数持てるのか？ (「グラナダ第3基地」のような名称は自動生成かユーザー命名か)

*   **未ログイン時の防衛ログ**: 防衛戦は非ログイン時でも自動で発生する仕様か？ (砲台の価値を高めるため、襲撃頻度の調整が必要)

## 6. 承認済み決定事項（2026-07-20 ユーザー承認）

- **モック**: 承認。通貨表記は実装時に実アプリと同じ「pt」へ統一する
- **発電所レート**: PO推奨案に減額。Lv1〜5 = **5 / 12 / 25 / 50 / 100 pt/時**（蓄積上限12時間・訪問時精算）
- **基地所有**: 1人1基地・ユーザー命名（後から変更可）
- **地形属性**: 基地作成時にユーザーが選択、以後 5,000pt で変更可能
- **修理ドック効果の再定義（PO判断）**: 現行アプリに時間経過回復が存在しない（修理は factory.ts の有償即時回復）ため、
  「回復2倍速」ではなく**修理費用割引 Lv1〜5 = 10/20/30/40/50%** とする
- **工場割引の対象**: PM-1 ではショップの機体購入価格のみ。改造費への適用は将来論点
- **砲台**: PM-1 ではレベル保持のみ。防衛戦への効果配線は PM-5 で実装
- **博物館**: PM-1 ではレベル保持のみ。展示枠の消費は PM-3 で実装
