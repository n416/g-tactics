# PM-3 機体博物館 UXノート

## 1. 画面構成の提案

**結論: 基地ページ内への統合ではなく、専用ページ（`/museum`）として独立させることを推奨します。**

*   **理由**: 
    *   博物館は「展示ホール」「図鑑（全911機の一覧）」「編集モード」と情報量が非常に多く、基地ページの1セクションとして埋め込むにはスペースが不足します。
    *   基地画面からは「博物館」施設パネルをクリックすることで `/museum` へ遷移する形が自然です。
    *   図鑑ページへの遷移も、博物館ホール内の「収蔵図鑑」部分をクリックするか、上部ナビゲーションから行えるようにします。

## 2. 編集フロー

### A. 展示機体の配置・入れ替え
1. ホール画面の「展示を編集する」ボタンを押下。
2. 画面が「展示編集モード」に切り替わる。
3. 画面下部（またはサイド）に「自分の収蔵機体リスト（インベントリ）」が表示される。
4. インベントリから機体を選択し、配置したい空き枠（または入れ替えたい枠）をクリックして配置する。
5. 「変更を保存」ボタンで確定し、ホール画面へ戻る。

### B. 殿堂機体・館長コメントの設定
1. ホール画面の殿堂エリアにある「殿堂を設定」ボタンを押下。
2. モーダルまたは専用編集領域が開き、収蔵機体から1機を選択するUIと、テキストエリアが表示される。
3. コメント（最大100文字程度を想定）を入力し「保存する」を押下。
4. ホール画面に反映される。

## 3. 必要になるデータの一覧（テーブル構造素案）

PM-2で定義された `user_unit_stats` とは別に、博物館の展示状態を管理するテーブルが必要です。

*   **`museum_settings` (ユーザーごとの博物館設定)**
    *   `user_id`: PK
    *   `featured_unit_id`: 殿堂展示している機体のID
    *   `curator_comment`: 館長コメント（テキスト）
    *   `updated_at`: 更新日時

*   **`museum_exhibits` (展示枠ごとの配置情報)**
    *   `user_id`: PK
    *   `slot_index`: PK (1〜24の展示枠番号)
    *   `unit_id`: 配置している機体ID (未配置は行が存在しないか NULL)
    *   `updated_at`: 更新日時

## 4. 論点リスト

1.  **展示対象は「機体種」か「個体」か？**
    *   *現状の想定*: PM-2の `user_unit_stats` に基づき「機体種（unit_id）」ベースでの展示を想定しています。
    *   *論点*: 同一機体を複数所持している場合、特定の1機（個体）を展示する仕様にするか否か。現状は `user_unit_stats` の累計データ（総撃墜数など）を表示する仕様がシンプルで推奨されます。
2.  **売却して未所持になった機体の扱い**
    *   *論点*: 一度入手して図鑑に登録されたが、現在は手元にない機体を展示できるか？
    *   *提案*: `user_unit_stats` で `obtained_count > 0` であれば展示可能（記憶の展示）とする方が、ユーザーのコレクション体験を損ないません。
3.  **図鑑（911機一覧）表示時のパフォーマンス**
    *   *論点*: 911機を一度にDOM描画すると重くなる可能性があります。
    *   *提案*: 実装時に仮想スクロール（Virtual Scroll）またはページネーションの導入を検討する必要があります。
4.  **コメントの制限と公開範囲**
    *   *論点*: 不適切発言の防止とレイアウト崩れ対策。
    *   *提案*: 文字数は100文字程度に制限し、改行は2回までとするなどのUI側でのバリデーションが必要です。

## 5. 承認済み決定事項（2026-07-20 ユーザー承認）

- **モック**: 承認（展示枠数の表記ミスのみ実装時修正: 枠数は Lv1〜5 = 4/8/12/18/24 が正）
- **画面構成**: 専用ページ `/museum`。基地ページの博物館施設パネルとプレースホルダー区画から遷移
- **展示ポリシー**: 機体種（unit_id）単位、**現所持のみ展示可**。
  売却して手放した機体は展示から外れる。実装は売却側にフックを足さず、
  **表示時に所持（hangars または characters.unit_id）を照合して未所持の展示枠を空き扱いにする**
  （配置時にも所持チェック）。図鑑の「収蔵」記録（obtained_count>0）は所持と無関係に残る
- **殿堂機体**: 展示と同じポリシー（現所持のみ）。館長コメントは最大100文字
- **テーブル**: UX-NOTES 3章の `museum_settings` / `museum_exhibits` 素案を採用
