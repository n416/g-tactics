# 引き継ぎ: 戦闘画面の地形背景（実装済み・調整フェーズ）

最終更新: 2026-07-16（夜）

## 現状

**全5地形の背景がデバッグ戦闘画面で動いている。** 方針は「コードで描く（SVG/CSS）」から
**「ChatGPT でレイヤーシートを生成 → スライス → パララックス」に転換**した（同日朝の旧版はこの点が古い）。

- 戦闘アニメは `BattleAnimation.tsx` がスパロボ風レイアウト
  （全画面パララックス背景＋左右に機体＋上部ステータスプレート＋下部メッセージ窓）。
- 地形ごとのレイヤー構成は `BattleAnimation.tsx` の `TERRAIN_BG`（高さ%・底上げ%・周期秒）。
- 継ぎ目は「[原画][左右反転]…を translateX(-50%) ループ」の**鏡像連結**で構造的に解消。
- `meta.terrain` は **optional（過去リプレイに無い）**。未指定は地上(1)。

## パイプライン（再現手順）

1. ChatGPT（Web, 無料枠）に既存シートを添付し「同フォーマットで◯◯地形」を発注。
   発注文の要点: **真横視点の書割 / 消失点禁止 / 中央凹み・左右対称禁止 /
   ②③④は背景を塗らずモチーフ外は完全透明 / 段間は透明の隙間**。
2. 透過PNGをダウンロード → `tmp-terrain-test/slice-sheet.mjs <sheet> <prefix>` でスライス
   （アルファ空行で自動分割。pngjs 必要）。
3. 全景しか出なかった場合はスクラッチパッドの fade-top.mjs 相当（上部αフェード）でレイヤー化。
4. `frontend/public/images/terrain/` に配置し `TERRAIN_BG` に登録。
